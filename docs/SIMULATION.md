# 平衡模拟

本文描述当前源码；“指定 pH 与气体逸度”是尚未发布的新增功能。应用使用用户选择的外部 Reaktoro Python 环境。

## 工作区与模拟步骤

数据库、模拟、结果在左侧同级切换。窄导航栏同时显示图标和名称，左上角按钮展开导航抽屉；顶部只显示当前页面的名称和操作。结果可在未打开数据库时独立使用，切换到数据库不会丢失当前模拟或图表。未选库时进入模拟，会先打开数据库选择，选好后直接进入模拟；也可改为只浏览数据库。

模拟包含以下四页：

1. **系统物种**：定义允许参与平衡的全部物种。每个方块显示名称和化学式，点击选中，再点击移除。搜索、相态和已有的 118 元素周期表共同筛选候选；元素匹配可选“组成仅限所选”“包含全部”“包含任意”。筛选本身不会改变体系。固定工具栏下方的网格独立滚动。默认按基础物种 → 络合物浏览，水、H⁺、OH⁻ 优先，随后是单原子物种、常见无机配体和其他水相物种，再到矿物与气体。同化学式的不同记录相邻展示；悬停或键盘聚焦可比较参数、来源与文献。也可切换为常用、名称或相态顺序。排序只是浏览分类，不定义求解器的基准物种，也不改变体系选择。
2. **初始物质**：从系统 species 中建立一份或多份 composition，例如原始流体、岩石、补充盐水。数量支持 mol、g、kg。一份 composition 可以被不同点重复加入，每次都计为新的外部投料。
3. **计算流程**：在同一页填写首轮、后续轮次各自的第一步和后续步。每处直接设置 T、P、Composition 和结束条件，预览显示路径与各轮之间的物料传递；长流程按重复步骤归纳，点选可核对附近的条件和用量。
4. **活度模型**：选择水相及气相模型，查看排版后的方程、参数、单位、离子尺寸来源和求解设置。

底部摘要显示基础字段的填写进度，可点击缺项直接打开对应页面，或使用“下一步”顺序设置；顶部标签始终可自由切换。摘要不判断模型的科学适用性，也不提前求解；“已填写，运行前检查”不等于配置已通过验证。自定义 Python 的算法不由 UI 摘要判断，实际检查和错误按运行程序返回。

**系统 species 与投料含义不同。** 选入体系、但初始量为零的 species 可以在平衡中生成。删除某种初始投料不会删除系统 species。切换页面保留搜索和当前编辑状态。

当前数据库中已不存在的 species 单独列出，可逐项或全部移除。移除体系 species 时，同步清理 composition 投料、统一来源、逐位置来源及四处组成中的指定 species，以及水溶剂和本次离子尺寸记录。若某项参数正改变该 species 的每份含量，则清理相应引用，同时保留路径位置数、轮数及其他参数。清理支持撤销；恢复关联设置时保留随后对其他内容的修改，不覆盖用户重新指定的水溶剂或变化量。

新建模拟预选可唯一识别的水、H⁺、OH⁻，初始投料仍为空。数据库若有多份 OH⁻ 等数据版本，会提示在“基础水相”中选择，不自动决定热力学版本；存在多个水溶剂候选时也不擅自选择。已有模拟和刻意清空的物种选择保持原样。可以移除基础物种建立纯矿物或纯气相体系。

“暂不可算”显示具体记录和原因。当前非水液相 Liquid 尚未接入相模型，不会当作水溶液或晶体矿物处理。草稿、重名记录等也分别解释。

## 设置反应过程

计算按两个方向组织：向右是同一轮的下一步；向下是下一轮的同一位置。首轮与后续轮次各有“第一步”和“后续每一步”，四处输入同时显示。每处只需填写温度 T、压力 P 和 Composition，再填写本轮及整个模拟何时结束。单点与多点使用同一布局，当前不经过的位置保留设置。

直接输入数值或公式，无需先选择变化方式：

| 输入 | 含义 |
| --- | --- |
| `250` | 温度固定为 250 °C。 |
| `T - 50` | 在温度栏中，采用前一步温度减 50 °C。 |
| `700` | 压力固定为 700 bar。 |
| `Psat(T)` | 根据本步温度使用纯水饱和蒸汽压。 |
| `250 - 10*i - 5*N` | 温度按步与轮次同时变化。 |
| `list(i, 250, 220, 180, 100)` | 按路径位置取指定数列，可重复或往返变化。 |

`i` 是从 0 开始的路径位置，`N` 是从 0 开始的轮次。T、P 通常取前一步的实际条件；在每轮第一步，取上一轮起点。压力公式中的 T 表示**本步已计算的温度**。`Tr`、`Pr` 始终取上一轮同位置的温压。整次模拟的第一步没有前驱，应填写初始数值或只依赖已有量的公式。用量公式中的 T、P 是本步条件；`X` 取该项前一步用量（每轮起点取上一轮起点），`Xr` 取上一轮同位置用量。上一轮未到达的位置不能被引用；下一轮增加的步骤需明确填写条件或用量。

结束条件直接使用比较式。例如 `i = 3` 计算 4 步，`N = 2` 计算 3 轮；`P < 150` 在压力首次低于 150 bar 时结束该轮。**满足条件的当前步仍会计算**，所以从 700 bar 每步减 5 bar，`P < 150` 包含最后的 145 bar，而 `P <= 150` 在 150 bar 结束。首轮与后续轮次可以有不同长度。总轮次条件只使用 N；每轮结束条件可使用 T、P、i、N。未在 10,000 步或轮以内达到条件会报错，计算规模上限为 20,000 个平衡点。

Composition 把“从哪里取、取哪些、取多少”放在一行。选择新 composition、前一步、上一轮同位置或指定位置，再选择全部物料、水相、固相、气相或指定 species。各行相加后求平衡。“×”后的数值或公式表示新 composition 的份数，或已有输出的取用比例：1 表示一份或全部，0.5 表示半份或 50%。新 composition 可大于 1，已有输出不能超过 1。未列出的物料不会自动加入。用量可依赖 i、N、T、P，与温压采用相同的公式规则。

新 composition 的 species 选项仅来自该 composition；反应后结果可从全体系选择。勾选状态和已选数量明确显示，支持搜索、清除。切换来源后仍保留已选 species，不在新来源中的选择会明确标出，需要移除或重新选择。新投料下方按相态、species、份数显示实际加入量。composition 的基准内容在“初始物质”中编辑；“添加指定条件”可进一步设置其中某个 species 的每份含量、pH 或气体逸度。

“复制…”可将其他位置的 Composition 及关联用量复制到当前格，之后分别编辑。它不建立持续同步，也不把某个水岩反应示例作为默认传递规则。

预览根据规模展示流程。短流程直接显示各点；长流程用“首轮起点、首轮后续步骤、后续轮次起点、后续步骤”表示重复结构，标明路径长度、轮数和实际温压、投料及取用比例的范围。范围由全部有效点汇总，不只抽取首尾，也不表示条件恒定。某项物料只在部分步骤取用时，明确标出次数，点击可定位不取用的位置；局部条件单独列出并可定位。各轮长度不同时显示实际步数范围。

横向箭头表示每步取用前一步的结果，纵向箭头表示取用上一轮同一位置的结果；相态和比例均依设置显示。`+` 表示新投料，指定其他位置的来源另外标明，不添加从一轮末尾回到下一轮起点的物料箭头。点击一组步骤或输入坐标可展开最多 3 × 3 个连续邻近位置，概览始终保留；图外来源可在所选点详情中直接跳转。单独设置和零取用保持原计算含义，概览不会修改配置或计算数量。“单独调整此处”仍只修改所选点。

局部改变后，直接按 i、N 计算的公式保持原规律；依赖 T、P 等实际前驱的公式则从改变后的值继续。例如第 3 步改为 100 °C，后续 `T-10` 得到 90 °C，而 `250-10*i` 仍遵循原数列。**参数承接与物料传递分别设置**，改变温度公式不会自动接收水相或固相。

旧设置保留原参数含义及局部范围；存在多项局部条件时直接列在对应输入旁，可就地编辑。含复杂逐位置物料来源、无法无损转换的旧配置保留原编辑方式。

`Psat(T)` 使用 Wagner–Pruss 纯水饱和曲线，适用 0.01 ≤ T < 373.946 °C。它指定纯水参考压力，不计算盐水或混合气的泡点，也不自动加入气相。首轮可填写 `Psat(T)`，后续轮次填写 700；温度和 Composition 独立设置。界面帮助提供 [IAPWS 来源](https://iapws.org/technical-guidance/release/Supp-sat)。

右上角可直接切换数据库；不同数据库保留自己的模拟历史。跨库计算先创建组合 `.rtdb`，支持系统和个人数据库，并预览同名参数冲突和依赖。来源文件保留；结构通过不意味着不同数据集的标准态与模型约定已经科学相容。

## 指定 pH 与气体逸度

普通平衡由投料、温压和模型决定 pH 与气体逸度。只有希望把其中一项作为已知条件时，才在“添加指定条件”中添加它。

- **指定 pH**：填写目标值和用于调节的中性化学式，例如 HCl 或 NaOH，再选择“只加入”或“允许加入或移出”。调节物质不限于示例，但其元素须由当前化学体系支持。软件求解所需的物质量，不会暗中添加反离子。允许负 pH，不把输入限制在 0–14。
- **指定气体逸度**：选择当前数据库中的气体记录，填写正的逸度值（bar）。这表示与外界交换气体以维持目标；不要求把有限气体投料或实际气相加入体系。逸度与气体分压含义不同。

两类目标都直接填写数值或公式，并支持局部设置。每个目标还可限制在某些轮次或位置生效，范围外回到由物料决定的平衡；预览显示本次实际施加的目标。“调整某处数值”和“只在某些位置施加目标”是两件事，分别由局部参数与目标适用范围控制。

同一反应点不能指定两个 pH 目标，或重复指定同一气体的逸度。多个目标对应的外部交换需要独立且足以确定平衡；冲突、欠定或所选调节物质无法达到目标时，计算会给出错误，不把未满足的目标当成成功结果。“只加入 HCl”不能靠移出 HCl 实现升高 pH。

输出同时记录目标值、实际值、当点净交换量与累计净交换量；正值表示加入，负值表示移出。`constraints.csv` 为逐点明细，`summary.csv` 中也有对应的数值列，可作为结果图的指标或横轴。元素收支采用“新投料 + 外部净交换 = 当前累计库存”，将外部交换与普通 composition 投料分列。初始汇合物料的电荷检查仍然生效。

参数代码中的 `equilibrium_constraints` 保存每项目标的类型、来源、适用范围和基准值。`schedule.parameters` 与局部 `overrides` 通过 `target: {"kind": "equilibrium_constraint", "constraint_id": "..."}` 引用相应目标，保存、代码切换和运行共用这些设置。

## 物料如何衔接

每个位置先汇合该处组成列表中的全部物料，再以实际元素量和电荷作为约束，求解该温压下的 Gibbs 能最小值。沿完整路径反应后进入下一轮；最后一轮完成后停止。

| 物料来源 | 实际含义 |
| --- | --- |
| 新配方 | 加入配方定义的物料，计为新的外部投料；同一配方使用两次，就是两次加入。 |
| 本轮前一步的结果 | 取用本轮紧邻的前一个位置输出；起点没有这一来源。 |
| 上一轮同位置的结果 | 取用上一轮在相同路径位置的输出；第 1 轮没有这一来源。 |
| 其他位置的结果 | 取用所选位置在本轮或上一轮的输出；每次取用时，来源都必须已经完成计算。 |

四处的列表直接表示实际组成。例如一份示踪剂只在首次起点加入，就只在首次起点添加该项。后续反应若需要含示踪剂的流体，应取用对应的反应后水相；再次选择示踪剂配方则是新增投料。

**取用比例始终以来源位置的原始输出为基准。** 把位置 1 的 25% 传到位置 2，再把 75% 传到位置 3，会完全分配位置 1 的输出。不能把同一份输出的 100% 同时传给两个位置，也不能在本轮用完后再在下一轮重复使用。“全部物料”与“指定物种”等重叠选择，同样检查逐物种的总分配比例。复杂分流若需要各位置使用不同规则，可使用保留的逐步路线或修改程序；四类组成中的“其余位置”共用同一份设置。

未转移的物料保留在累计库存中，不自动参加后续反应。取用水相、保留矿物或气体的操作需明确填写；来源列表不会自动补足未列出的相。汇合后的实际物料仍须满足电荷约束。

温度输入 °C，压力输入 bar。路径与轮次规定计算顺序，**不自动赋予物理时间、流速或停留时间**。数值初值只帮助求解器收敛；当前物料总量始终由实际组成决定。

## 常见反应过程

| 目的 | 组成与条件设置 |
| --- | --- |
| 单点平衡 | 一个路径位置、一轮，在首次起点加入需要的配方与份数。 |
| 独立温压扫描 | 温度或压力按范围或数列变化；首次起点和首轮后续位置都加入新配方，多轮时也在后续轮两格加入新配方。 |
| 封闭温压路径 | 首次起点加入原始配方；首轮后续位置取用本轮前一步的全部物料。条件沿路径变化。 |
| 部分回流并补料 | 一个路径位置、多轮。首次起点加入起始配方；后续轮起点取用上一轮结果的一部分，并另加新配方。 |
| 分离气体或指定组分 | 后续位置只取用需要继续反应的相或物种，其余物料留在库存中。 |
| 多来源混合 | 在同一格中加入多项来源，各自选择物料范围和数量，汇合后共同求平衡。 |

一个多轮冲刷水岩反应可以按以下四格设置，流体与岩石先分别保存为配方：

| 反应位置 | 本处加入的物料 |
| --- | --- |
| 首次起点 | 新流体配方 + 新岩石配方。 |
| 首轮后续位置 | 本轮前一步的水相 + 新岩石配方。 |
| 后续轮起点 | 新流体配方 + 上一轮同位置的固相。 |
| 后续轮其余位置 | 本轮前一步的水相 + 上一轮同位置的固相。 |

这会在首轮的每个位置加入新岩石，而每一轮只在起点加入新流体；其他位置接收流经前一步的水相，后续轮次继续使用各位置反应后的矿物。若岩石配方代表整条路径的总量，应给首轮各位置设置对应的分配份数。气相是否继续参与、各处取用比例及温压变化都由实际模型另行填写，不由这个示例自动决定。

相同温度下，程序可采用邻点或上一轮结果作为数值初值；失败时尝试实际投料初值。矿物渐进初始化只改善首点求解，最终计算始终使用完整物料量。

## 图形设置与 Python 代码

顶部的“图形 / 代码”开关切换当前模拟。六个参数模块预填图形界面的物种、composition、统一条件与用量、各处物料来源、活度模型和求解设置，支持字面量、列表、字典和有限数字运算。随后八个执行模块展示运行环境、体系与求解器、初始状态、平衡求解、物料库存、结果提取、循环与状态传递、运行保存。代码直接包含实际的 `ChemicalState`、`EquilibriumConditions`、`solver.solve()` 与循环；默认源码从正式求解器生成，避免显示内容与后台逻辑分离。

代码中的 `schedule` 与图形界面的反应步骤使用同一份配置，当前结构的 `version` 为 `1`：

- `positions` 和 `rounds` 保存解析后的最大路径长度和总轮数；没有结束表达式时仍按这两个数量执行。
- 可选 `stop` 的 `first`、`later`、`rounds` 分别保存首轮、后续轮次、整个模拟的结束表达式。每轮实际长度独立计算。
- `parameters` 保存通常参数；每项的 `target` 指定温度、压力、composition 某个 species 的每份含量，或某条物料来源的份数／取用比例。
- `value` 指定变化方式：`fixed` 为固定值；`linear` 同时给出 `start`、`path_step` 和 `round_step`；`list` 用 `along` 选择 `path` 或 `round`，并填写 `values`；`relative` 按该方向的实际前驱值增减；`water_saturation` 仅用于压力；`expression` 用 `expression` 字段保存直接输入的数值公式。
- `overrides` 保存局部设置，每组的 `positions`、`rounds` 用 `start`、可选 `end` 和 `step` 选择范围，再用 `parameters` 列出要改的参数。范围编号从 1 开始；省略 `end` 表示当前末端，省略 `step` 表示连续选择。

`linear` 的起点按所选范围的局部顺序计算；`relative` 的 `step` 则加在实际紧邻前一步或上一轮同位置的数值上。只有该方向没有前驱时，才使用 `start`，并由 `other_step` 调整另一个方向的起点。`relative` 不表示重新取用物料。代码中的结果取用比例为 0–1，例如 `0.5` 表示 50%，与新界面的乘数一致。新 composition 的来源 `fraction` 则是份数，可大于 1。

`reaction_stages` 保存四处物料组成，键为 `first_start`、`first_following`、`later_start`、`later_following`，每个值是一份来源列表。图形设置、代码、保存文件和正式执行共用参数与来源标识；改用量时通常只需改数值，不需要更改标识。启用四处组成后，不叠加旧的统一来源或逐点来源。

旧的 `loops`、逐点温压及逐轮压力设置仍按原含义兼容读取；新模拟使用 `schedule`。公式支持有限算术、比较及 `min`、`max`、`abs`、`sqrt`、`ln`、`log10`、`exp`、`list`、`Psat` 函数，不执行 Python 或 JavaScript。自定义算法在执行模块中编写。

修改执行模块后标记“自定义 Python”。执行模块支持 Python 导入、函数、循环及自定义求解逻辑。UI 预览仍按参数绘制；切回 UI 只同步参数，不覆盖自定义算法。修改图形参数后再运行，使用最新参数和保留的执行模块。“恢复标准求解代码”保留当前参数，将执行模块恢复为正式实现，并保留一份代码恢复副本。

每次运行在独立子进程的全新命名空间中，从第一个模块顺序执行全部代码。这里不提供 Jupyter 内核或逐格执行历史。载入文件、检查语法、切换界面不会执行用户代码；点击运行才执行。语法检查不能预判任意 Python 的收敛或模型正确性。

参数错误与语法错误显示模块和行号；运行异常同样定位到执行模块。失败或停止后保留已写入的完整点。自定义输出须保留 `summary`、`species`、`balances` 等结果接口：点编号从 0 连续递增，同一张表的列在运行中保持一致，暂缺值使用 `None`；非有限数、重复物种、不完整结构和超额结果会在写入前拒绝。

未完成编辑可以用“保存设置”或 ⌘S 保存原始文本与上次有效参数。旧版六模块设置自动补充执行模块；未修改的标准执行模块随版本刷新，用户编辑过的执行模块和参数原始文本保留。运行文件包含完整代码、配置与程序指纹，结果明确标记自定义运行；自定义模型与守恒检查的科学有效性需由使用者核对。

执行环境提供 `snapshot`（数据库与参数副本）、`progress`（进度）、`emit`（逐点保存）和 `output_directory`（本次运行目录）。`program.py` 是本次完整代码的可读副本，依赖 EasyReaktoro 运行上下文与外部 Reaktoro，不能脱离该环境单独双击运行。重新载入 `simulation.ersim.json` 可在应用中复现和修改。

数据库记录的适用温压可在详情中查看；范围外仍可计算。模型本身无法求值、无效温压或求解失败仍会报错。数据库单物种性质检查保留原有的记录范围检查。

## 活度模型

界面中的方程对应本次所调用的模型，包含水活度；所有公式由本地 KaTeX 渲染，无须联网。

- **Extended Debye–Hückel**：逐离子尺寸 aᵢ、随温压变化的 NaCl bγ、摩尔分数转换 log₁₀Xw，以及配套水渗透项。中性溶质 γ = Xw。水密度来自 HGK 液态分支，介电常数来自 Johnson–Norton。动态参数随每点结果保存。
- **Davies**：Reaktoro 的化学计量离子强度实现，默认离子经验系数 0.3、中性溶质盐析系数 0.1，并显示相应水活度方程。
- **Helgeson–Kirkham–Flowers (HKF)**：Reaktoro 的水相活度模型，显示 Born 系数、半径与温压参数。它与数据库中计算标准化学势的 HKF 方程是不同层次的设置。
- **PHREEQC：Debye–Hückel / Davies**：直接打开官方 PHREEQC 数据库后，按其物种参数选择相应分支，包括 LLNL。此选项不实现 Pitzer 或 SIT；对应参数库会被拒绝。
- **理想水溶液**：溶质 γ = 1；水活度按理想质量摩尔浓度标度的 Gibbs–Duhem 关系计算，并非对所有组成固定为 1。
- **气相**：理想气体或 Peng–Robinson。气相组分的活度通过逸度计算；Peng–Robinson 所需临界性质不存在时会明确失败，不代用其他物质参数。

EDH 的离子尺寸先取“本次指定”，其次取数据库记录。指定值须附参数来源和使用理由，保存在本次配置中。“沿用数据库的默认尺寸”采用已保存且被标记为默认赋值的数值；“沿用有理由但无文献的尺寸”采用已保存数值和理由、但没有文献的记录。两种情况可能同时出现。新模拟默认允许这两类记录，已有明确选择保留，可在当前模拟的活度模型页修改。两者都不会凭空补齐缺失尺寸，缺少尺寸时仍阻止计算。

活度页面先显示必要参数，再显示可展开的公式。缺失尺寸或来源会列出具体物种，并可直接展开参数表。切换到其他活度模型会保留完整的指定参数；若有尚未填完的编辑，可返回 EDH 补全，或明确清除这些未完成项。

应用按用户选择的活度模型计算，不设置 NaCl 50% 组成门槛或液态水经验筛查门槛，也不添加结果可靠性提示。数学域、缺失参数、无法求值或实际求解失败仍会给出具体错误。

本版对照的原生实现：[Davies](https://github.com/reaktoro/reaktoro/blob/v2.13.0/Reaktoro/Models/ActivityModels/ActivityModelDavies.cpp)、[HKF](https://github.com/reaktoro/reaktoro/blob/v2.13.0/Reaktoro/Models/ActivityModels/ActivityModelHKF.cpp)、[PHREEQC](https://github.com/reaktoro/reaktoro/blob/v2.13.0/Reaktoro/Models/ActivityModels/ActivityModelPhreeqc.cpp)、[理想水相](https://github.com/reaktoro/reaktoro/blob/v2.13.0/Reaktoro/Models/ActivityModels/ActivityModelIdealAqueous.cpp)、[气相状态方程](https://github.com/reaktoro/reaktoro/blob/v2.13.0/Reaktoro/Models/ActivityModels/ActivityModelCubicEOS.cpp)。更换外部 Reaktoro 版本后，应重新核对其实现与参数。

## 计算与持久保存

模拟顶部的“已自动保存”表示参数及代码已写入本机历史文件，不代表已产生计算结果。“保存设置”导出配置，“保存工作区”导出已载入的数据和图表；计算结果则由运行过程自动保存。

点击“运行”先检查配置，再弹出 macOS 文件夹选择窗口。程序在所选位置以模拟名称创建结果子文件夹，不自动添加日期或随机字符串；路径分隔符等文件名禁用字符会替换。若同名结果已存在，可选择“覆盖结果”替换该结果文件夹中的内容，或“另存为…”填写新的结果名称，同时保留两次结果。另存只改变本次结果名称，不修改模拟名称；新名称也会检查是否已存在。只有可识别且允许覆盖的结果目录提供覆盖选项，其他已有文件或目录需另存。

取消保存位置或同名处理不会启动计算。启动后自动进入“结果”页查看进度和数据，每个有效点完成后立即写入。

| 文件 | 内容 |
| --- | --- |
| `summary.csv` | 条件、pH/Eh、离子强度、水活度、求解方式、逐点误差和动态参数。 |
| `aqueous.csv` / `mineral.csv` / `gas.csv` | 体系中各相 species 的入口量、平衡量、净变化量、活度及系数；molality 仅对水相溶质适用，矿物、气体及水溶剂留空。 |
| `component_balance.csv` | 每点各元素与电荷的输入、输出和误差。 |
| `process_balance.csv` | 每点完成后的累计外部投料、未转移库存及误差。 |
| `transfers.csv` | 每条生效来源实际转移的物种量，含来源位置、反应轮次和分配比例。 |
| `simulation.ersim.json` | 可重新载入的完整参数与本次执行代码。 |
| `program.py` | 与本次模块一致的 Python 源码副本；需要 EasyReaktoro 运行上下文。 |
| `input.json` | 开始计算时的完整数据库记录快照，包含当时未保存的数据库修改。 |
| `metadata.json` / `run.json` / `status.json` | 数据来源与指纹、版本、参数审计、进度和结束状态。 |
| `points.ndjson` | 逐点完整记录；每条写入后刷新并同步至磁盘，是中断恢复的数据依据。 |
| `Result Explorer.html` | 嵌入全部已保存点的独立离线探索器。完成或正常停止时生成；异常中断后重新打开目录时重建。 |
| `worker.log` | 本次计算进程的诊断输出。 |

逐点守恒要求元素与电荷的绝对误差不超过设置的 mol 限值；累计账允许误差限值随已完成点数线性累加，界面与文件同时保留实际误差。累计账的定义为：**累计外部投料 = 全部尚未转移的输出库存**。

失败或停止时只保留完整通过逐点与累计守恒检查的结果。崩溃后最后未写完的记录会被忽略；派生 CSV 和探索器可以从完整记录重建。应用退出、切换运行时或移除最近记录，不会删除已保存结果。重新打开恢复的是已有结果，尚不支持从中断处自动续算。

“保存设置”或 ⇧⌘S 使用系统保存对话框另存 `.ersim.json`。每份模拟以独立 JSON 文件保存在当前用户应用数据目录的 `Simulations/` 中，包括未完成数值和原始代码。文件编号与可修改的模拟名称分开；历史条目显示实际 JSON 文件名，“显示文件”在 Finder 中定位该文件。路径根目录随电脑用户变化。

载入 `.ersim.json` 会创建一份独立的模拟历史副本，并使用当前选择的数据库。继续编辑和保存该副本不会写回原设置文件；复现原计算需选择相应数据库。分享或备份设置也不会把数据库嵌入其中。

默认自动保存，可在软件常规设置中关闭，改用顶部“保存”或 ⌘S。手动模式有未保存修改时，切换模拟、数据库或退出会显示居中的保存、放弃、继续编辑选项；保存失败保留编辑。运行仍保存本次配置和计算快照。

撤销和重做覆盖物种、配方、路线、模型、参数及代码状态，保存后仍可撤销；记录在本次打开期间保留。“恢复到上次保存”可回到保存状态，且该恢复仍可撤销。输入框与代码编辑器使用其自身文本撤销；顶部撤销按钮用于整体模拟。

“新建”创建独立模拟，“历史”可搜索、复制、切换并恢复其关联结果；新建不会覆盖上一份。“移到最近删除”将历史文件移入本机的可恢复区域，结果文件保留。正常历史与最近删除都提供“永久删除”，确认后删除本机对应的模拟 JSON 设置与代码文件，结果和数据库文件保留。最近删除中也可恢复模拟，或使用“一键清空”确认删除当前列出的全部设置；确认期间新增、恢复的记录不会被误删。晚到的自动保存不会使已删除记录重新出现。历史保留数据库引用，重算仍需原数据库。旧版数据库草稿打开时自动迁入，原缓存保留；旧 `.ersim.json` 迁移保留原有物料含义。

返回应用时会刷新历史文件状态。若当前模拟的文件已在 Finder 等外部程序中删除，当前编辑仍保留在窗口；保存或离开时可“保留为新模拟”“放弃当前编辑并继续”或“继续编辑”。新模拟使用新文件编号，已删除的原文件不会被自动保存重新创建。若删除的是结果目录，则只清除关联结果入口，模拟本身及其参数仍保留。

## 结果

进入左侧同级的“结果”，或点击模拟步骤右侧的“查看结果”。“打开已保存结果”选择 EasyReaktoro 计算生成的整个结果文件夹，恢复已完成点、运行状态与守恒记录；已有 CSV/HTML 使用“导入表格 / 工作区”。顶部左侧的“历史”记录已打开的计算目录及导入、另存的 HTML 工作区，分别标为“计算结果”和“图表工作区”。可按名称或保存位置搜索，点击对应记录重新打开；移除记录不影响本地文件，CSV 和图片导出不单独进入历史。运行状态旁的“保存位置”在 Finder 中显示实际结果文件夹。

新计算结果记录真实的路径位置、反应轮次及每点温压，不把同一位置上同时变化的多个参数合并成一个“变量值”。图表可选择路径位置、温度、压力或其他已输出指标作为横轴。旧结果仍保留原有变量列、名称和单位；内建序号名称显示为“路径位置”“反应轮次”，自定义字段及原始数据保留。

图表左上角的“结果首页”返回打开/导入入口，保留当前数据、图表、采样位置、书签和面板布局。点击“继续查看”回到原视图。首页期间暂停播放，方向键不移动隐藏的采样点；后台计算更新不会强制跳回图表。取消导入或导入失败保留原数据。

探索器初始不预选物种。可按名称/相态搜索并选择 species 或系统状态；每张图独立选择数据，支持多图、原值多轴、对数尺度、纵轴范围、横轴方向、条件叠加、连续浏览、游标、参考点、书签与变化定位。选择连线时仅连接已保存采样点，不插值、不平滑；变化区间不是精确相界。

“导入表格 / 工作区”可读取已有 CSV、CSV.GZ、JSON 或探索器 HTML。图的 SVG、当前图 CSV、含数据和视图的 HTML 工作区导出，均通过系统保存面板选择位置。字段与采样点面板可分别收起，拖动分隔线调整宽度；分隔线聚焦时左右键微调，Home 恢复默认宽度。专注图表按钮同时收起两侧面板，再次点击恢复。显示设置与播放选项按需展开，主要空间用于图表。切换工作区暂停播放并保留数据与视图。

图表布局、播放、显示方向与面板直接在结果页调整，随工作区保存，不再提供重复的结果偏好窗口。嵌入结果跟随整个应用的语言与主题；独立 HTML 保留自身语言选项。

横轴支持 pH、系统性质和 species 数值。以这些性质为横轴时，“数据呈现”默认采用散点，每个 X/Y 对都来自同一次计算；重复或非单调的 X 值保留为各自采样点。“展示”默认选“当前轮次（含叠加）”，也可选择“全部已载入轮次”一起比较；没有轮次字段的导入数据对应显示当前条件或全部已载入条件。

需要观察变化过程时，在“图设置 → 数据呈现”选择“按采样顺序连线”，并用“采样顺序”选择移动和连接的顺序。每轮或每组条件分别连接，不跨轮次连成一条线，也不按性质横轴数值重新排序。缺失值不补零、不插值，连线在缺失处断开。

矿物、气体和水溶剂的 molality 不适用，显示为空；这不代表它们的物质量没有保存。比较矿物生成或消耗时，可选择平衡量 `amount_mol`、入口量 `inlet_amount_mol` 或净变化量 `delta_amount_mol`，单位均为 mol。水相溶质的 molality 使用 mol/kg 水。

采样点和条件的前后按钮支持长按连续移动，松开、移出按钮、切到其他窗口或到达边界时停止。左右键沿当前采样顺序浏览，上下键切换当前浏览的轮次或条件；空格控制播放或暂停。

结果界面跟随应用浅色、深色或系统主题，坐标、网格和曲线同步适配。SVG 使用适合独立导出的浅色背景；HTML 工作区保留图、条件、参考点、书签、面板布局和语言，单独打开时可以选择主题。嵌入应用时由应用控制主题。界面中已知字段提供中文名称，原始列名与数值保持不变。

导入独立数据后，后台计算继续运行；自动预览刷新不会替换该数据，可通过“返回计算结果”主动切回。格式错误的导入保留原工作区。保存工作区直接打开一次系统保存面板，取消不会显示保存成功；`⌘S` 保存当前页面对应的内容。

大结果按反应轮次及路径位置分段预览，每次最多载入约 500,000 条物种记录。界面明确显示当前部分；该视图的图表和工作区导出仅含已载入数据。原始 CSV 和运行目录中的独立探索器保留全部完成点。新计算尚无有效点时清空上一计算的数据，迟到的旧响应不会覆盖当前结果。

## 当前边界

这是由显式物料传递连接的**指定温压平衡计算**。当前尚未实现动力学速率/时间积分、对流弥散方程、固溶体、自动 pH/Eh/逸度开放储库约束，或多个独立气体混合相。矿物作为纯相；水相须选择唯一的 H₂O 溶剂且各实际入口含正水量。纯矿物或纯气相体系不强制添加水。

单次最多 500 个物种、100 份配方、每点 30 条来源规则、最多 10,000 个路径位置及 10,000 轮反应、20,000 次平衡和 2,000,000 条物种结果，以先达到的限制为准。

pH/Eh 来自运行时能提供的 AqueousProps，无法取得或无水相时留空。Eh 的地球化学解释需核对氧化还原约束。接近数值下限的微小正物种量不能作为矿物出现的证据。物质守恒、求解收敛和数值回归通过，不等同于对任意化学体系的科学验证。

同一运行刷新和切换预览轮次/位置范围时保留图表选择与样式；书签和参考点按全局计算点编号恢复。位于其他点段的标记暂时隐藏并显示行内说明。工作区导出仍仅包含当前载入的数据；跨点段标记的会话缓存不会扩充导出数据范围。
